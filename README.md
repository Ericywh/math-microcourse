## 网站发布
GitHub Pages: Settings → Pages → Deploy from a branch → main → /docs。

## 更新规则
计量经济学课程共10章120节，数学微课程共6章73节。只有完整讲义已实际交付并写入公开仓库时，目录中才可以标记为“已归档”。

数学微课程新增课页应存至 `docs/math/lessons/`，并更新 `docs/math/catalog.js` 中对应课程的 `published`、`date` 与 `url`。修改 `main` 分支后，GitHub Pages 将重新部署。ChatGPT 定时推送不保证仓库自动写入。请勿将私人学习档案、非公开课程及其 Git 历史推送到此仓库。

此仓库从空仓库创建，不继承私人档案库的提交历史。
