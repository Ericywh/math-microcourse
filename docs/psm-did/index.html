采用Card与Krueger（1994）的NJ/PA快餐店最低工资政策数据。包含政策前后的就业结果及处理前协变量，适合讲解PSM-DID的目标估计量和实证步骤。

原作者公开数据ZIP · 整理版Stata数据 · 变量说明

仅一期政策前数据不能检验政策前动态趋势；政策由两个州对比，不应将常规标准误解释为可靠的州级政策推断。
