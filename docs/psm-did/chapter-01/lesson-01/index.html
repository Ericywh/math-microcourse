一、真实数据：最低工资政策评估

后续全课程拟复用Card与Krueger（1994）的新泽西州和宾夕法尼亚州快餐店调查。1992年4月1日新泽西州最低时薪从4.25美元上调至5.05美元，邻州宾夕法尼亚州未同步上调。原研究涵盖410家快餐店，含两轮就业结果与处理前协变量。

要素研究设计
处理组新泽西州（NJ）快餐店
对照组宾夕法尼亚州（PA）快餐店
政策前 / 后1992年2—3月 / 1992年11—12月
结果变量全职等价就业（FTE）
可用处理前协变量连锁品牌、公司直营、政策前就业、起薪

作者公开原始数据ZIP；本节Stata与Python统一使用教学整理版minwage.dta，并参考字段及样本筛选说明。原调查的410家餐厅不等于每个分析变量都无缺失的样本规模。仅有一期政策前观测，无法直接检验处理前动态平行趋势；政策在州一级发生而只有两个州，常规聚类渐近推断受到明显限制。

二、双重差分解决什么问题？

若NJ的就业人数在政策后增加2人，不能直接认为政策增加2个岗位，因为两州都会受到景气和季节需求等变化影响。DID先计算每组政策前后变化，再扣除未受政策处理的对照组变化。时间差分消去时间不变的组别差异，组间差分扣除两组共同变化。

识别难点不在减法，而在于对照组能否代表“处理组没有政策时本应出现的就业变化”。

三、反事实与ATT

设$D_i=1$表示处理组、$D_i=0$表示对照组。$t=0$为政策前、$t=1$为政策后；$Y_{i1}(1)$表示政策后接受处理时的结果，$Y_{i1}(0)$表示同一餐厅没有接受处理时的结果。

$$ATT=E[Y_{i1}(1)-Y_{i1}(0)\mid D_i=1]$$

ATT是实际受处理餐厅的平均政策效应。对同一餐厅，政策后的两种潜在结果无法同时观测。DID希望用对照组的平均变化构建缺失的反事实。

四、平行趋势假设

$$E[Y_{i1}(0)-Y_{i0}(0)\mid D_i=1]=E[Y_{i1}(0)-Y_{i0}(0)\mid D_i=0]$$

其含义是：如果没有政策，两组的平均就业变化应相同。这里要求的是变化相同，并非政策前的就业水平相同。例如NJ为18人而PA为15人，原有水平差异不必然破坏识别。

还需注意无预期效应、无实质政策溢出、没有造成组间趋势分歧的重要同期冲击，以及调查口径和样本组成可比。

五、2×2手算案例

以下全部为教学构造数值，不是Card–Krueger真实样本的估计结果。

组别政策前政策后就业变化
NJ处理组1820+2
PA对照组1514−1

在平行趋势假设下，PA减少1人意味着NJ在没有政策时也应减少1人，即由18变成17。实际NJ就业为20，二者之差为3。

$$\widehat{ATT}_{DID}=(20-18)-(14-15)=2-(-1)=3$$

实线为观测数据，绿色虚线为假设下的NJ无政策反事实，垂直距离为DID估计量。

六、两期DID回归模型

$$Y_{it}=\alpha+\beta D_i+\gamma Post_t+\delta(D_i\times Post_t)+\varepsilon_{it}$$

$\alpha$表示PA政策前的平均结果；$\beta$表示两州政策前均值差；$\gamma$表示PA前后的平均变化；交互项系数$\delta$就是DID估计量。在无额外协变量的两组两期饱和回归中，交互项OLS估计等于上述四格均值的双重差分。它能否解释为ATT依赖识别假设。

七、Stata与Python使用同一真实数据

以下两段代码保留相同的配对完整样本（sample==1）并排除政策前后FTE缺失。两套程序的DID点估计理论上应相同。代码未在本次课程中完成Stata与Python双端实际运行核验，因此不报告未经核实的真实估计数值。

Stata

* 第1章·第1节：使用统一的真实NJ/PA最低工资数据
* 数据说明：https://ditraglia.com/erm/ps4-q3-minwage.html
* 文件需可联网访问；也可先下载到本地再修改use路径
use "https://ditraglia.com/data/minwage.dta", clear

* 两轮均有工资与就业数据的餐厅；保留本课所需非缺失项
keep if sample == 1
keep if !missing(state, fte, fte2)

* state=1表示新泽西州，state=0表示宾夕法尼亚州
* fte是政策前全职等价就业；fte2是政策后
generate double d_fte = fte2 - fte

* 查看两州两轮样本均值与各自变化
tabstat fte fte2 d_fte, by(state) stat(n mean)

* 两期DID等价的变化量回归，state系数就是DID点估计
regress d_fte state

* 警告：政策仅在两个州之间变化；上述常规OLS标准误
* 不应解释为可靠的州级政策冲击显著性推断。

Python

import pandas as pd
import statsmodels.formula.api as smf

# 与Stata相同的Card-Krueger NJ/PA数据教学整理版
url = "https://ditraglia.com/data/minwage.dta"
df = pd.read_stata(url, convert_categoricals=False)

# 统一样本定义，确保前后FTE均不缺失
df = df.loc[df["sample"] == 1].copy()
df = df.dropna(subset=["state", "fte", "fte2"])

# state=1代表NJ处理组；0代表PA对照组
df["d_fte"] = df["fte2"] - df["fte"]

# 两州就业前后和就业变化均值
means = df.groupby("state")[["fte", "fte2", "d_fte"]].mean()
print(means)

# 手工组间平均变化差异
did = means.loc[1, "d_fte"] - means.loc[0, "d_fte"]
print("DID估计值：", did)

# 用变化量OLS验证点估计，不将默认标准误作为可靠州级推断
model = smf.ols("d_fte ~ state", data=df).fit()
print("回归DID系数：", model.params["state"])

源文件：Stata .do；Python .py。这里不对默认OLS标准误作可靠的州级政策推断，因为两个州不足以支持常规州级聚类渐近近似。

八、三个重要误区

  1. DID大于零就证明因果效果为正：并不成立，仍依赖平行趋势、无预期和无溢出等条件。
  2. 两组政策前均值必须一致：不需要，固定水平差异允许存在。
  3. 只有一个政策前时期也能验证平行趋势：不行。能计算DID，但不能用政策前动态来检验这个假设。

九、两分钟自测与参考答案

理论题：政策前处理组和对照组就业平均为20人和30人，能否断定DID不适用？

计算题：处理组由12增加至17，对照组由10增加至13，DID是多少？

答案：（1）不能。DID要求无政策时的平均变化相同，而非初始就业水平相等。（2）$(17-12)-(13-10)=2$。在条件成立时表示处理组相对无政策反事实平均增加2人。
