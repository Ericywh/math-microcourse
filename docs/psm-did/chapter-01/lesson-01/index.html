第1章·第1节｜DID的基本原理

为什么处理组与对照组的政策前后变化差异，可以用于估计政策效应？

课程以四章十节循序展开：DID、PSM、结合识别、匹配诊断、双软件实证、推断与完整研究。本节只建立DID的反事实逻辑。

一、真实数据与研究背景

后续全课程复用Card与Krueger（1994）对新泽西州（NJ）与宾夕法尼亚州（PA）快餐店的调查。1992年4月1日，新泽西州最低时薪由4.25美元提高至5.05美元，宾州未同步提高。原研究调查两州410家快餐店，有政策前后结果和处理前店铺特征。

研究要素定义
处理组 / 对照组NJ / PA快餐店
政策前 / 后1992年初 / 1992年末
结果变量全职当量就业人数（FTE）
处理前协变量品牌、经营权、政策前就业及工资

作者公开原始数据 ZIP（解压后 public.dat 为主体、codebook 为说明）；另见NBER论文资料。这套数据只有两期、仅两个州，无法直接检验政策前平行趋势，政策层面的聚类推断也存在局限。以下表中数值均为教学案例，不是实际研究的样本均值。

二、反事实与ATT

如果NJ就业增加了3人，不代表政策创造了3个岗位。即使没有政策，经济景气、季节需求等也可能引起就业变化。

设 $D_i=1$ 是处理组，$D_i=0$ 是对照组；$Y_{i1}(1)$ 为单位$i$在政策后受处理时的潜在结果，$Y_{i1}(0)$ 为未受处理时的反事实结果。处理组平均处理效应为：

$$ATT=E[Y_{i1}(1)-Y_{i1}(0)\mid D_i=1].$$

对于同一个已受处理的单位，我们不可能同时观察到它未受处理时的就业。DID的目标是借助对照组变化来重建这一缺失的反事实变化。

三、2×2案例：手工算出DID

组别政策前政策后变化
NJ（处理）2023+3
PA（对照）2221−1

如果没有政策，两组平均就业变化相同，则NJ无政策时政策后就业应为$20-1=19$。实际就业是23，因此反事实差距是4人。

$$\widehat{ATT}_{DID}=(\bar Y_{T,1}-\bar Y_{T,0})-(\bar Y_{C,1}-\bar Y_{C,0})=(23-20)-(21-22)=4.$$

实线为观测结果，绿色虚线为依据平行趋势构造的反事实。

4是需要识别假设支撑的估计量，不是直接观察到的政策因果效应。

四、平行趋势是识别关键

平行趋势不是“政策前结果水平相同”，而是“如果没有政策，两组应当经历相同的平均结果变化”。

$$E[Y_{i1}(0)-Y_{i0}(0)\mid D_i=1]=E[Y_{i1}(0)-Y_{i0}(0)\mid D_i=0].$$

本例政策前NJ为20、PA为22，水平差异不破坏DID。若NJ因为其他经济冲击原本就会比PA多增加4人，估计量就可能被错误地解释为政策效应。无预期效应、无显著溢出、无重要的同期混杂干预、样本组成合理等也是实证时必须考虑的条件。只有一个政策前观测期，无法直接验证政策前趋势。

五、两期DID回归模型

$$Y_{it}=\alpha+\beta D_i+\gamma Post_t+\delta(D_i\times Post_t)+\varepsilon_{it}.$$

$\alpha$是政策前PA均值，$\beta$是两组政策前水平差异，$\gamma$是PA随时间的平均变化，$\delta$是NJ额外变化。在标准两组两期、没有额外协变量的模型中，交互项OLS系数$\delta$等于前述双重差分；只有条件成立时才解释为ATT。

Python

import pandas as pd

# 第1章·第1节 DID基础；数字为教学案例，非真实研究样本
df = pd.DataFrame({
    "treated": [1, 1, 0, 0],
    "post": [0, 1, 0, 1],
    "y": [20, 23, 22, 21]
})
means = df.groupby(["treated", "post"])["y"].mean().unstack()

# 计算处理组与对照组的前后变化
change_t = means.loc[1, 1] - means.loc[1, 0]
change_c = means.loc[0, 1] - means.loc[0, 0]
did = change_t - change_c
print(f"DID = {did:.1f}")  # DID = 4.0
# 每组每期仅一个人为设定值，不能据此进行统计显著性推断。

七、三个重要误区

误区1：处理组政策后表现更好就说明政策有效。错误；政策后的组间差异可能来自原有水平差异。

误区2：DID可以消除所有遗漏变量偏差。错误；无法自动消除组间不同的时间变动冲击。

误区3：平行趋势要求政策前两组均值相等。错误；关键是没有处理时两组的平均变化应相同。

八、两分钟自测（含参考答案）

理论题：平行趋势是否要求处理前处理组、对照组的就业均值相同？
答案：不要求，只要求无政策时的平均就业变化相同。

计算题：处理组从50增到65，对照组从40增到48，DID是多少？
答案：$(65-50)-(48-40)=7$。
